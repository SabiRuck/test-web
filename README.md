# test-web# EduApp – Školský Testovací Systém

Moderná webová aplikácia postavená na frameworku **Python / Django** určená na efektívnu tvorbu, správu a online vyhodnocovanie školských testov. Aplikácia poskytuje učiteľom plnú kontrolu nad bankou otázok a študentom prehľadné rozhranie na testovanie. 

Aplikácia je úspešne nasadená v produkčnom prostredí a dostupná online.

## 🔗 Produkčný odkaz (Online Demo)
- **Živá aplikácia:** https://test-web-fsmn.onrender.com/

## 🚀 Hlavné Funkcie (Features)
- **Dashboard učiteľa:** Centrální rozbočovač, správa existujúcich testov a rýchle akcie
- **Banka otázok:** Modul na vytváranie nových otázok a ich opätovné použitie v rôznych testoch
- **Konfigurácia testu:** Úprava nastavení, viditeľnosti testu pre žiakov a správa parametrov
- **Prehľad výsledkov:** Zobrazenie úspešnosti študentov v prehľadných tabuľkách
- **Moderné UI/UX:** Dizajn s plynulými prechodmi a dynamickým farebným podsvietením (glow efekt) dôležitých prvkov a navigácie

## 🛠️ Použitý Technologický Stack
- **Backend:** Python 3.11+, Django Framework
- **Frontend:** HTML5, CSS3 (Custom Modern UI, Flexbox layout)
- **Databáza:** SQLite3 (Lokálne vývojové prostredie) + Firebase Realtime Database
